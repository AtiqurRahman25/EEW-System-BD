## 📊 Dataset

This project uses the **STEAD (STanford EArthquake Dataset)** dataset.

📥 **[Download STEAD Dataset from Google Drive](https://drive.google.com/file/d/1E27oZM3T6IrN5Fdwfu_DGrRqOFt53pZm/view)**

### Why Is the Dataset Hosted Externally?

The dataset is hosted on Google Drive instead of being included directly in this GitHub repository for the following reasons:

1. **Large File Size:** The dataset exceeds 350 MB, which is beyond GitHub's recommended 100 MB per-file limit.
2. **Repository Performance:** Including the entire dataset would significantly increase the repository size and make cloning and downloading more time-consuming.
3. **Easy Accessibility:** Hosting the dataset externally allows users to download it separately when required without affecting repository performance.
